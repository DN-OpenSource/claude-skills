The product manager

The newest skill ran on this repo and produced the goal, roadmap and decisions on this page.

product-visionary · new in 1.5.0

Works out the goal, maps every feature to it, then lets a panel decide what to do.

It finds real issues with test-report, has 3, 6 or 9 agents argue each decision, and acts only as far as you allow at the start of the session.

How they work together

None of these is required. Each pairing makes the other skill better when both are installed.

codebase-guardian+memory

Guardian reads MEMORY.md before editing and writes what it learned back after.

lsp+codebase-guardian

Find every reference before deciding how big a change is.

schema-aware-db+lsp

Map real ORM call sites instead of grepping a table name.

agents-dox+everything

AGENTS.md contracts govern how the other skills edit each folder.

teammates+codebase-guardian

Each peer agent follows the safe-edit loop for its own work item.

ponytail+memory

The end-of-session tail folds durable follow-ups into MEMORY.md.

product-visionary+test-report

Finds issues and proves every fix with 2 positive and 1 negative test.

decision-maker+everything

Fast typed yes/no and pick-one calls inside the other skills, with confidence.
